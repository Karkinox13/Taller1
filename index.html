Bienvenido

Este proyecto corresponde al Taller N.º 1 de la asignatura Desarrollo de Software V.

Su objetivo es aplicar conceptos básicos de JavaScript mediante la resolución de cuatro ejercicios prácticos que utilizan estructuras condicionales, entradas de usuario y procesamiento de datos en tiempo real.

Cada uno de los problemas se encuentra organizado en pantallas individuales para mantener una estructura clara, ordenada y fácil de navegar.

Desde este menú principal puedes acceder a cada ejercicio, interactuar con sus formularios y visualizar los resultados generados dinámicamente.

Selecciona un problema en la barra de navegación superior para comenzar.
